# TrebleEye

Poängräknare för dart (301/501/701) med kameraigenkänning och manuell inmatning.

Öppna: https://tomdooley93-max.github.io/Dartkollen/

**Installera på iPhone:** öppna länken i Safari → Dela → Lägg till på hemskärmen.

**Ny version:** ändra `index.html` och höj `VERSION` i `sw.js` (och `appVer` i `index.html`). Installerade appar visar då "Uppdatera".
